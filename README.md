# v13.8 可輸入搜尋下拉選單

本版以 v13.7 為基礎，將庫存明細查詢的料號、倉庫、色號、業務、業務部門、等級、客戶、訂單類別與胚布類型改為可輸入搜尋下拉選單。輸入 A 顯示 A 開頭，繼續輸入 AB 則顯示 AB 開頭。選項採後端即時前綴查詢，不受原先一次載入 500 筆的限制。

# 庫存分析與明細查詢 UI v13.8

## v13.7 快照條件調整與兩期差異暫停

- 移除一般分析頁面的「分析快照日」下拉選單。
- 一般分析固定查詢 `dbo.vw_InventoryInquiry_Base` 目前最新庫存，不再傳入快照日期條件。
- 「3. 兩期存貨差異」頁籤設為 disabled，使用者無法點入。
- 兩期差異的 HTML、JavaScript、API 與 SQL 程式全部保留，待確認歷史快照保存方式後再啟用。
- 分析來源說明改顯示「資料範圍：目前最新庫存」。
- 明細查詢及 v13.6 欄位順序完全保留。

## 延續 v13.6 明細欄位順序調整

明細查詢畫面、Excel 匯出及 CSV 匯出使用相同欄位順序：

- `料號`：移到 `異動日期` 後面。
- 下列欄位依序移到 `儲位名稱` 後面：
  - `訂單類別代碼`
  - `訂單類別`
  - `Final Buyer ID`
  - `Final Buyer名稱`
  - `中文色名`
  - `英文色名`
  - `興采色號`
- 結果最後依序排列：
  - `規格`
  - `品名`
  - `零元專案否`
  - `Tranzend上架品名`
- 各 Type View 若沒有其中某個欄位，程式會略過該欄位，其餘欄位仍正常顯示。
- 未指定位置的欄位維持各 View 原始欄位順序。

## 延續既有功能

- 分析頁籤固定使用 `dbo.vw_InventoryInquiry_Base`。
- `彈性否` 直接使用 View 中的 `彈性`／`非彈性`。
- 不由應用程式跨資料庫 JOIN `snx_ima_file`。
- 302 專案判斷：批號第 2 碼起 4 碼為 `1132` 或 `3132`。
- 明細 `類型`、`胚布類型` 顯示中文。
- 明細資料來源、篩選、分頁、排序及匯出機制維持原設計。
